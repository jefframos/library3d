# Ambient sounds (birds)

Free bird and nature recordings, downloaded 2026-11-02. They are not packed into any game yet: copy the ones you want into games/<slug>/raw-assets/audio/ and run npm run pack:audio.

## Licenses

- **mixkit/**: [Mixkit Sound Effects Free License](https://mixkit.co/license/). You can use them in commercial and personal projects, games included, and credit is not required. You may not redistribute them as standalone sound files, for example as a sound pack.
- **opengameart-cc0/**: CC0 (public domain). No restrictions and no credit required.

Mixkit files are the full-quality WAV downloads. The number at the end of each file name is the Mixkit sound ID. The ambience / one-shots split was made from the titles, so a few files may be in the wrong folder.
