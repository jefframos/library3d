3D Desert Plants Pack - low-poly LOD
Generated with polyy.ai

39 desert plants in GLB format. Decimated LOD meshes with JPEG-compressed colour maps.
Cacti (saguaro, barrels, prickly pear, organ pipe, columns and clusters),
agaves, aloes, yuccas and sotol, palms, desert trees and shrubs, a dead
snag and a saguaro skeleton. Same style as the conifer and deciduous
tree packs: the plant alone, no ground.

Contents
  models/    GLB meshes, one file per plant
  previews/  animated turntable GIF for each plant, same filename
  LICENSE.txt

Engine notes
  Godot 4:   drag the .glb into the FileSystem dock and instance the scene.
  Unity:     GLB needs glTFast or UnityGLTF; both read these files directly.
  Unreal 5:  Import the .glb through the Content Browser.
  Blender:   File > Import > glTF 2.0.

Mesh details
  One mesh and one PBR material per file, with base colour and
  metallic/roughness textures embedded (JPEG/PNG). No normal maps.
  Roughly 3,733 to 12,847 triangles per plant.
  Y-up. The origin sits at the centre of the bounding box, and each
  model is normalised to fit a box about 1 unit across, so set the
  scale to suit your scene (a barrel cactus and a palm ship at the
  same size) and drop the pivot to the base.
